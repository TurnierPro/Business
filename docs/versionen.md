# Versionen von Levarex OS

Die Nummer steht unten rechts in Levarex OS und unter `/api/gesundheit`. Regel: kleine Änderung → hinten um 01 hoch
(1.00 → 1.01), größere Änderung → vorne hoch (1.xx → 2.00). Die neueste Version steht oben.

| Version | Datum | Was ist neu |
|---|---|---|
| 1.02 | 24.11.2026 | Portal-Vorschau, Testbetrieb als Standard, Konnektoren und Einstellungen aufgeräumt, kleinere Diagrammschrift, Beleg per Handy-Foto oder Scan |
| 1.01 | 24.11.2026 | Versionsnummer auch auf der Anmeldeseite |
| 1.00 | 24.11.2026 | Erste Version auf dem Server (Hostinger, Coolify): Compose ohne Caddy, Testbetrieb (Mails nur intern), eigenes Postfach je Person mit Ablage in „Gesendet“, Notfall-Werkzeug zum Zurücksetzen des Passworts, Versionsnummer |
